# Note for the theory team — closing the state-tracking gap

**Context.** In the emergent-chess experiment (`mscn/chess_world.py`) the IBF
coherence model learns, from opaque move tokens alone, to *prefer legal moves*
(opening ~72% legal@1, ~79% legal@5) and the **8×8 board geometry emerges** from
move co-occurrence (Procrustes disparity ≈ 0.06). But legal@1 **decays with game
depth** (opening 72% → endgame 23%). This note states the gap precisely and
proposes formal routes to close it.

---

## 1. The gap, stated precisely

Chess move sequences are generated by a **deterministic hidden process**:

- hidden state `s_t` = the full board position (≈ a point in a finite but huge
  state space);
- the rules give a deterministic update `s_t = T(s_{t-1}, a_t)`;
- the **legal-move set** `L(s_t)` and the optimal-move distribution are functions
  of `s_t`, *not* of the recent token window.

Our current predictor keys coherence on a **fixed-order context** (the last `k`
move tokens): `δR[ctx_k][a]`. This is a Markov-order-`k` model in token space.
The trouble: the move-token process is **not** order-`k` Markov for any fixed
`k` — two histories with identical last `k` tokens can reach different positions
`s`, hence different legal sets. So the model is approximating a function of the
state with a function of a window, and the approximation error is exactly the
ambiguity that the window throws away.

**Formal statement of the ceiling.** Let `C_k(h)` be the last-`k`-token context
of history `h`, and `S(h)` the resulting position. For any predictor that
factors through `C_k`,

```
  legality-error  ≥  E_h [ 1 − max_a  P(a ∈ L(S) | C_k(h)) ]
```

and this is bounded below by the residual state uncertainty
`H(S | C_k)` (Fano). Empirically `H(S | C_k)` is ~0 in the opening (few histories
per context) and grows fast into the midgame — which is exactly the decay we see.
**The fix is not more data or larger `k`; it is conditioning on a sufficient
statistic of the history rather than a window.**

---

## 2. What "closing the gap" means

Find a learned map `φ` from histories to a representation `z_t = φ(h_{≤t})` such
that `z_t` is a **sufficient statistic for prediction**:

```
  P(a_{t+1} | h_{≤t})  =  P(a_{t+1} | z_t)        (predictive sufficiency)
```

The minimal such `z` is the **causal state** of the process (Crutchfield &
Shalizi's computational mechanics): histories are equivalent iff they induce the
same future distribution, `h ∼ h'  ⇔  P(future | h) = P(future | h')`. For a
deterministic-transition process like chess the causal-state partition is a
*coarsening of the position space* (positions with identical move-futures merge,
e.g. transpositions). So:

> **Target.** Learn `φ` whose induced partition of histories **refines the causal
> partition** of the chess process. Then coherence keyed on `z = φ(h)` attains
> legality → 1 and the predictor becomes position-aware without ever being given
> the rules.

This reframes "track the board" as "learn the minimal predictive partition" —
which is squarely in IBF's wheelhouse, because IBF already has a *coarse-graining*
postulate (Postulate II) and a *renormalisation* apparatus for finding relevant
vs irrelevant structure.

---

## 3. Three concrete routes (in increasing ambition)

### Route A — Recurrent coherence state (an "IBF world-model")
Maintain a latent configuration updated each ply by a **learned IBF map**

```
  z_t = G(z_{t-1}, a_t),     a_{t+1} ~ Boltzmann(k · R̂_eff(z_t, ·))
```

where `G` and the modification map `δR̂(z, a)` are trained to maximise predictive
coherence (the same discrepancy-driven dynamics, Postulate IV, but on `z` instead
of a token window). The board state is then the **fixed structure** the recursion
converges to. Questions for the team:

- Conditions on `G` (contraction / basin invariance — Theorem 2) under which `z_t`
  converges to a faithful encoding of `s_t`.
- Does the gradient-flow / modification ODE admit a `G` whose attractors are in
  bijection with reachable positions?

### Route B — Causal-state / PSR construction via coarse-graining
Build `φ` *directly* as a predictive-state representation: represent a history by
its vector of predicted next-move coherences, then **coarse-grain** (Postulate II)
histories with equal prediction vectors. This is the ε-machine construction done
with IBF coherence as the prediction operator. Questions:

- Show the coarse-graining that minimises predictive coherence-loss converges to
  the causal-state partition (an IBF restatement of the ε-machine optimality
  theorem).
- Tie the renormalisation-group flow (`RenormalizationGroup.lean`) to causal-state
  refinement: relevant operators ↔ distinctions that change the move-future;
  irrelevant ↔ transpositions.

### Route C — Compositional binding on the emergent geometry
Stage 2 already recovers a square manifold from data. Represent the position as a
set of **(square, piece-role) bindings** on that manifold and let moves update the
bindings. Piece roles can be discovered unsupervised by clustering moves by their
displacement signature on the recovered manifold (rook = rank/file, bishop =
diagonal, knight = L). Question: can a binding/coherence update reconstruct `L(s)`
compositionally, giving legality → 1 with an interpretable state?

---

## 4. Measurements to settle it

1. **Legality vs context order** `k` ∈ {0,1,2,3,…}: confirm it saturates well
   below 1 (evidence the ceiling is structural, not data-limited).
2. **State recoverability probe** (à la Othello-GPT): train a *linear* probe from
   the representation `z` to the true board occupancy; report per-square accuracy.
   Window contexts should plateau; a sufficient `z` should approach 100%.
3. **`I(S ; z)`** — mutual information between true position and the learned
   representation; the gap to `H(S)` is the residual to close.
4. **Causal-state count**: estimate the number of distinct prediction vectors vs
   the number of distinct positions; their ratio measures how much legal
   transposition-merging is achievable.

---

## 5. Why this is the interesting IBF question

The associative ceiling is not a failure of the framework — it is the precise
point where IBF's **coarse-graining / renormalisation** machinery should earn its
keep. "Tracking the board" = "learning the causal-state partition" = "finding the
relevant coarse-graining of history." If Route B can be proved (IBF coarse-graining
→ ε-machine optimality), it would give a *non-neural, formally characterised*
world-model learner, and the board-state recovery would be a theorem rather than
an empirical probe. That is a stronger and more distinctive result than matching a
transformer's legality number.

**Suggested first deliverable for the team:** a proof or disproof of the Route-B
claim on a tractable sub-process (e.g. a 4×4 or king-and-rook endgame world, where
the causal states are enumerable), with the legality-vs-`k` and linear-probe
curves as the empirical anchor.

## 6. Update — theory-team response (now formalized)

The team formalized this note (`../formal/CausalStates.lean`, arXiv:2604.07108).
Confirmed:

- **Route B is a theorem.** For deterministic-transition processes with injective
  observable profiles, a representation is predictively sufficient **iff it refines
  the state partition** (`causal_state_optimal`); the state map is the *unique
  coarsest* sufficient representation, and an IBF coarse-graining (Postulate II) is
  valid iff it is sufficient. So "learn the causal-state partition" is now precise.
- **Route A has an exact condition.** A recurrent update `z_t = G(z_{t-1}, a_t)` is
  sufficient **iff it simulates the process**: ∃ decoding σ with `σ(init)=s₀` and
  `σ(G(z,a)) = T(σ(z), a)` (`recurrent_sufficient_of_simulation`) — an algebraic
  homomorphism from the move monoid into the state space.
- **The window ceiling is a theorem, not a guess** (`window1_not_sufficient`): the
  toggle process exhibits two histories with the same last token reaching states
  with different legality.

**What this changes for the build.** The kernel chess model represents context as a
recency-weighted **sum of move embeddings** — precisely a lossy window/sum map the
toggle counterexample rules out. Empirically the pure kernel does not beat the exact
n-gram on legality. The theorem says no kernel over a lossy context can; the fix is a
**simulation-faithful recurrent state** (Route A) whose update commutes with the
move dynamics. That homomorphism condition is now the concrete target for the next
prototype.
